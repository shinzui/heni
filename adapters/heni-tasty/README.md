# heni-tasty

Replace Tasty.defaultMain with heniMain. Native Tasty selection is intersected with HENI_SELECTOR during an attempt. Outside Heni, normal framework behavior is preserved.

Add `heni-tasty ==0.1.0.0` to the test component and select `"adapter": "heni-v1"` in the Heni case. Complete attempt-bound records prove selected/executed IDs and named failures. Missing, stale or partial evidence cannot count as detection.

See the [adapter guide](https://github.com/shinzui/heni/blob/master/docs/user/adapters.md) and packaged test fixture for runnable examples.
