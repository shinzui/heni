# Representative migrations

Each family has a one-case default heni.json, a passing unchanged target and a
precise intended witness. Replacement and patch-catalogue use a standalone Cabal
capacity assertion. Generated-code changes generator input before compilation.
Diagnostic-checker compiles and executes its own workspace-local validator.

All files are independently authored BSD-3-Clause examples. Read
[the migration guide](../../docs/user/migration-guide.md) for commands, surviving and
adversarial variants, capability boundaries and the measured comparison method.
The integration trial is `sh scripts/test-migrations.sh` from the repository root.
